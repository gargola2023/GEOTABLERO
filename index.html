Conexiones

Bases de datos espaciales que los editores pueden usar como capas. PostGIS se conecta a través de Supabase, PostgREST, pg_featureserv (OGC API Features) o un WFS de GeoServer.

Cómo exponer tu PostGIS

Supabase: crea el proyecto, activa la extensión postgis, crea la tabla con su columna geometry en EPSG:4326 y usa la URL del proyecto con la clave pública. PostgREST o pg_featureserv: instálalos junto a tu PostgreSQL y habilita CORS. GeoServer: publica la tabla desde un almacén PostGIS y activa CORS o JSONP.
